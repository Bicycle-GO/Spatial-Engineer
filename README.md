# Spatial Engineer

공간정보융합산업기사와 공간정보융합기능사를 위한 두 가지 학습 트랙입니다.
각 트랙은 기본이론, 개별 챕터, 기출·예상문제 풀이 페이지로 나뉩니다.

- 산업기사: 44개 이론 단원(실기 기본이론 18개 포함), 필기 학습문제 48개, 실기 필답형 예상문제 67개와 사용자 제공 기출 3개
- 기능사: 19개 이론 챕터, 대화 속 문제 7개, 예상·개념 확인 문제 19개, 사용자 제공 이미지 기반 기출 34개(1차 자료 14개·2차 자료 20개)
- 두 트랙에서 투영법·공간분석·원격탐사·DB·코딩 등을 다룬 12개 인터랙티브 시각화 단원을 제공합니다.
- 산업기사에는 위상관계 규칙 그림 학습을 추가로 제공합니다. 포인트·라인·폴리곤별 4개씩 12규칙의 오류/충족 도형, 사례·예외·수정법과 규칙별 실기 예상문제 12개를 연결합니다.
- 도면 벡터화 그림 학습은 전처리 → 세선화 → 벡터화 → 후처리의 입력·출력, 농수로 사례와 예상문제 5개를 제공합니다. 스캔한 선형 도면의 중심선 추출을 설명하며, 세선화 결과인 래스터와 벡터 선 객체를 구분합니다.
- 벡터화 각 단계에 쉬운 비유·처리 전후·도로와 등고선 사례를 추가했습니다. 래스터 셀 값 결정의 대표 네 규칙과 공간위치 보정의 세 변환을 두 단원 및 예상문제 7개로 연결합니다. 셀 코딩의 네 분류는 Washington State Ecology 교육자료를 기준으로 하며 한글 명칭은 학습용 번역입니다.
- 이론은 그림, 개념·비교, 사례·문제 포인트로 나뉩니다. 문제는 단계별 해설과 관련 이론을 연결합니다.
- 산업기사 문제풀이는 `/engineer/practice/`에서 필기(`written`)와 실기(`practical`) 페이지를 선택합니다.
- 실기는 단답·서술·계산·코드형 답안 작성 → 모범답안 비교 → 학습용 기준 자가점검 → 복습 표시 순서입니다. 자동 채점이나 공식 점수 예측을 제공하지 않습니다.
- 실기 주요 목차는 Chapter 1 공간정보 분석, Chapter 2 공간정보서비스 프로그래밍, Chapter 3 공간정보 융합콘텐츠 개발입니다. 실기 목차·기본이론 목록·문제의 Chapter 필터가 같은 단원 매핑을 사용하며 기존 단원·규칙별 바로가기도 유지합니다.
- Chapter 1의 보정 결과 검토 단원은 RMS 오차 명칭, 3·4·5m 잔차와 3.54m 집계 계산, 낮은 기준점 RMS의 해석을 예상문제 3개로 다룹니다.
- NDVI 3문항·항공사진 계산 5문항·Python/Java 코드 출력 6문항·OGC 서비스 3문항·데이터 분류법 7문항을 추가했습니다. 코드 6개는 실제 Python·Java에서 실행해 출력값을 대조했습니다. 다섯 분류 명칭의 계산 기준과 자연분류/Jenks의 최적화 관계를 명시합니다.
- 실기 답안 초안은 저장 가능한 경우 이 브라우저의 localStorage에 보관됩니다. 자가점검 상태와 결과는 현재 학습 세션에서 유지됩니다.
- 이론 진도는 트랙별로 브라우저에 저장되며 기존 산업기사 진도도 이어집니다.
- 대화 속 문제는 제공된 공유 대화의 문항을 재구성했습니다. 실기 기출 탭에는 사용자가 제공한 공간정보 기초 문항 3개를 원문과 번호 순서대로 수록했습니다. 해당 문항의 시행 연도·회차와 공식 원문은 미확인입니다.
- 기능사 과정은 입문용 보조 학습 과정이며 공식 출제기준 전체를 대체하지 않습니다.
- 기능사 기출은 `/technician/practice/?source=past`에서 풉니다. 1차 자료 01–14번과 2차 자료 01–20번을 별도 선택하며, 2차는 `&paper=2`, 문항 번호는 `&question=4`로 바로 열 수 있습니다. 1차·2차는 사용자 첨부를 나눈 학습용 이름이며 시행 연도·회차·공식 원문은 미확인입니다. 문항 ID가 서로 달라 답안도 독립적으로 저장됩니다.
- 1차 자료의 1번에는 OR·AND·XOR·NOT 영역 비교, 2번에는 패키지·클래스·객체·상속부터 배우는 접근제어 설명, 5번에는 연산 기호와 식의 묶음 규칙을 배우는 Java 입문 해설을 제공합니다. 답안을 쓰기 어려울 때는 ‘답안 없이 해설로 배우기’를 선택합니다. 11~14번은 점·선·면, 지오코딩, UTM, 메타데이터를 사례와 그림으로 다룹니다.
- 2차 자료는 영상 필터·재배열·기하보정, GIS·DB 기초, OGC, 위상·중첩·논리 격자·재분류·최근접 보간을 다룹니다. 1번 중앙값 201, 11번 중앙값 100·9셀 평균 110으로 계산 오류를 보완했고, 6번은 원문 도식의 배경 포함 영역 번호와 실제 피처 가정의 조각 수를 구분합니다. 도면은 학습용 재구성이며 공식 기출 도면이나 GIS 엔진의 출력이라고 표시하지 않습니다.

## Local development

Node.js 22.13 이상에서 `npm ci`, `npm run dev`로 실행합니다.

- `npm run lint`: 코드 검사
- `npm run typecheck`: TypeScript 검사
- `npm test`: GitHub Pages 정적 빌드 및 페이지·링크 검사
- `npm run build:pages`: `/Spatial-Engineer` 경로를 적용한 정적 사이트 빌드
- `npm run dev:sites` / `npm run build:sites`: 기존 Sites/Vinext 환경

로고 원본은 `public/spatial-logo.svg`이며, 헤더와 파비콘에 적용되어 있습니다.

공유 대화의 반영 범위와 정정 사항은 [콘텐츠 출처 기록](docs/content-sources.md)에 정리했습니다.
